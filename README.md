# Tony Hoo — Personal Homepage

Static single-page site (no build step). Netlify publishes the repo root.

- `index.html` — the page (styles + script inline). Editable settings (WhatsApp number, project list) are in the `CONFIG` and `PROJECTS` blocks near the bottom.
- `assets/` — photos (skyline backgrounds, Tony's portrait, buyer photos reused from the KL Projects Atlas).

Related sites: KL Projects Atlas (`kl-property-atlas-tonyhoo`), Home Loan Calculator (`tonyhoo-home-loan-calculator`).
